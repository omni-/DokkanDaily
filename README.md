# DokkanDaily

*Daily challenges for the hit mobile game Dragon Ball Z: Dokkan Battle.*

[>> SITE LINK <<](https://dokkandle.net/daily)

DokkanDaily picks a new challenge every day. Clear it, upload a screenshot, and compete on the seasonal leaderboard.

It supports Global and JP clears and does a probably-unreasonable amount of OCR to figure out what you actually submitted.
